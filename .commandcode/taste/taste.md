# Taste

- When reporting a bug/regression, expects the agent to start by inspecting the git diff of the recent changes ("check diff") to find the cause, rather than guessing. Confidence: 0.7
- Files terse, single-line bug reports (e.g. "the application is getting stuck when opening") with no repro steps, logs, or stack traces; expects the agent to investigate, reproduce, and root-cause on its own. Confidence: 0.5
